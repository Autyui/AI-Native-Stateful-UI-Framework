# AIUI Bridge Bundle

Generated by AIUI. This folder is non-invasive and does not modify project source files.

Semantics:
- `AUI_UI_ENTRY.json` is a static export entry for embedding/rendering snapshots.
- `ui_runner.py` is the runtime controller for start/stop/log/anchors/rollback.

## Files
- `aui_bridge.py`: bridge launcher wrapper
- `aui_bridge_config.json`: startup command/flags config
- `aui_ui_protocol.json`: status bar + controls protocol

## Usage
```powershell
# optional check
python ./.aui-dashboard/bridge/aui_bridge.py --print-command
python ./.aui-dashboard/bridge/aui_bridge.py
```
